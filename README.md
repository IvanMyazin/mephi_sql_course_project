# Сессионный проект по PostgreSQL

Вариант 19: приложение для работы с автомобилями и водителями таксопарка.

## Подготовка

1. Установите Python 3 и PostgreSQL.
2. Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установите библиотеки:

```bash
pip install -r requirements.txt
```

4. Параметры контейнера указаны в `config.yaml`. Создайте локальный `.env`:

```bash
cp .env.example .env
```

Укажите в `.env` пользователя и пароль PostgreSQL. Файл `.env` добавлен в
`.gitignore` и не попадет в Git.

## Запуск

```bash
python main.py
```

При первом запуске приложение создаст схему `taxi_project` и пустые таблицы. Через пункт 2
главного меню можно пересоздать таблицы и добавить тестовые данные.

Пользователь выбирает автомобиль или водителя по номеру строки. Значения `id` в
интерфейсе не отображаются и не вводятся. При удалении автомобиля связанные с ним
водители удаляются автоматически.
